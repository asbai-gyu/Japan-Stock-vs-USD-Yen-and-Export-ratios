# Japan-Stock-vs-USD-Yen-and-Export-ratios
This repository is for my Python II class at CMU. This project will be analyzing the relationship between Japanese stock movements, export exposure, and Yen/USD conversion rates



Project Overview

This project investigates the relationship between USD/JPY exchange-rate movements, Japanese stock returns, and industry-level export exposure.

The analysis compares companies from multiple Japanese industries to determine whether more export-oriented industries exhibit stronger correlations between stock returns and exchange-rate fluctuations.



Reproducing the Analysis
* Download or clone this repository.
* Open Japanese Stock vs USD vs Exports.ipynb in the All Data and Notebook folder
* Run all cells of code
